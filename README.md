README · 玩家手册


它能做什么


一台只改"真值"的打印机。先使用 / 装备机器，再左键点商品，

在弹出的窗口里选档位，收 20 信用点，真值真的变了。

红机只能"假装"改（只动假值）；这台机器真值假值一起改，

所以游戏里的算价、验真、鉴定助手读到的都是同一个值。



怎么拿到机器


正式途径：供货商上门时买。
供货商每次来店里摆库存，货架上会多出一台未拥有状态的真实打印机，付款买下即可（默认 100 信用点）。他每次来都摆一台，可以一直买。



备用途径：F6 直领（默认关闭）。


在 ModManager → 真实打印机 面板勾上 EnableF6Give，按 F6 领取一台价值 0 的机器（防刷钱）。关闭时按 F6 无任何反应、不弹提示。



使用方法


步骤	说明
①	在仓库里找到「真实打印机」
②	右键 → 使用，或装备到手上
③	左键点击目标商品（香烟 / 化学品 / 金属锭 / 注射器）
④	在弹出的窗口里选档位，扣费写入
★ 直接拖动到商品上不会触发（与原版红机不同）。用法就是：先使用 / 装备，再左键点商品。

只支持这四类
你要的	说明
香烟    	真伪
化学品（含毒药）	纯度
金属锭	纯度
免疫宁注射器	真假 + 可否使用（两条真值都列出来）
毒药按化学品算 —— 游戏真值体系里没有「毒药」这一类。

其余类别（酒、水、装备成色、印花票…）点了会给一句人话提示，不开窗。

判定只认游戏内的类别，不写死物品名单 → 游戏加新物品自动支持。



外观
沿用原版红色标签打印机的外观，形状压到 1×2 格（原版是 2×3），图也等比缩到贴合格子 —— 都是为了让供货商货架上放得下。



配置项（ModManager → 真实打印机）
项	默认	说明
FeatureCost	20	改一次真值收多少信用点，设 0 = 免费
VerboseLog	关	详细日志。默认只打启动横幅、自检结论与报错；勾上才看流水
SupplierStock	开	供货商每次摆库存追加一台真实打印机
EnableF6Give	关	F6 直领开关。打开后按 F6 领取价值 0 的机器；关闭时不响应
★ cfg 改了立刻生效，不用重启游戏。



常见问题


症状	怎么办
mod 完全没反应	UserData/MelonPreferences.cfg 里没有 \[RealPrinter] 段 → mod 没被加载，确认 DLL 放对了
左键点物品没反应	先确认机器是"使用 / 装备"状态，不是"拖动"。若仍无反应，看启动日志有没有「Harmony 补丁已挂 ✓」


拖动到商品上没反应	正常行为，拖动不触发。用法：先使用 / 装备，再左键点商品
F6 按了没反应	正常 —— EnableF6Give 默认关闭。想用去 ModManager 勾上


供货商来了但货里没打印机	柜台满了。日志搜 \[供货商]；打「回读前柜台没找到」= 被游戏静默销毁，等下次补货
机器图比格子大	缩图失败，3 秒后自动重试；摆货与交互完全不受影响，只是显示溢出


改了没生效	面板勾上 VerboseLog，看「已执行档位动作」+「商品侧回读 最终 GetNegociatedValue=」


提示里"价值 X → X ★没变"	说明真没改。勾 VerboseLog 看回读断言


读档后失效	勾 VerboseLog 看「读档检查完成」的指针白名单条数（应 ≥1）


拖动机器会闪退	确认部署的是 v1.1.9+


面板里出现两行 RealPrinter	Mods/ 目录里有两个版本的 DLL，删掉旧的
一句话
拿到机器 → 使用 / 装备 → 左键点商品 → 选档位 → 扣 20 点 → 真值真的变了。
