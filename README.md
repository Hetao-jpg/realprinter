README · 玩家手册（v1.5.2）

它能做什么

一台只改"真值"的打印机。拖到商品上（或装备后左键点），在弹出的窗口里选档位，
收 20 信用点，真值真的变了。

红机只能"假装"改（只动假值）；这台机器真值假值一起改，还要执行档位的官方动作 ——
所以游戏里的算价、验真、鉴定助手读到的都是同一个值。

怎么拿到机器

正式途径：供货商上门时买。
供货商每次来店里摆库存，货架上会多出一台未拥有状态的真实打印机，付款买下即可（默认 100 信用点）。
他每次来都摆一台，可以一直买。

备用途径：F6 直领（默认关闭）。
在 ModManager → 真实打印机 面板勾上 EnableF6Give，按 F6 领取一台价值 0 的机器（防刷钱）。
关闭时按 F6 无任何反应、不弹提示。

怎么用

两种触发方式，任选其一：

① 拖动（与原版红色标签打印机、放大镜一致）
   按住左键把「真实打印机」拖到目标商品上松手 → 弹出改值窗口。

② 装备后点击
   右键 → 使用 / 装备 → 左键点目标商品 → 弹出改值窗口。

然后：选档位 → 扣费 → 真值写入。

改完会发生什么（默认打赃物标记）

真值改成功后，机器会按原版机制给商品打上赃物标记（热度）——
之后安检、拒收、折价、热度衰减全部交回游戏原版系统处理。
不想要这个效果：在 ModManager 面板把 MarkStolenOnEdit 关掉，就只改真值、不打标记。

已知副作用：

· 已经带高热度赃物的商品再改真值 → 热度按新的商品价值重算并覆盖（可能变低 = 相当于"洗白"）。
· 赃物标记一旦打上，商品提示里会一直显示赃物标记，直到游戏原版热度衰减机制把它清零。


能改哪些


★ v1.5.0 起：开放**游戏官方档位目录里的全部类别**（16 类），是红色标签打印机范围的超集。

香烟真伪 · 化学品（含毒药）纯度 · 金属锭纯度 · 免疫宁注射器真伪与可用性
印花票真伪 · 效期 · 酒品质 · 装备成色 · 新鲜度
凹陷 · 生锈 · 已开封 · 仿制品 · 赠品 · 模块状态
· ⚠ 水不支持 —— 改水的价格容易破坏游戏经济平衡（主动排除）。

· 判定只认游戏内的 category，**不写死物品名单** → 游戏加新物品自动支持。
· 毒药按化学品算 —— 游戏真值体系里没有「毒药」这一类。
· 参考：红机自身有 3 类不给改（金属锭 / 装备成色 / 酒），本机作为"真值机"一并开放。
· 其余没有真值特性的东西（放大镜、垃圾桶…）点了不会开窗，也不打扰你。


存放


v1.5.0 起可以放进**档案箱**和**工具箱**：

· 档案箱 —— 靠 `MAGNIFYING_GLASS`（与红机、放大镜同一条白名单）
· 工具箱 —— 靠 `TOOLBOX_ITEM_TAG`（工具箱白名单认 identifier=="labeler"，本机走 tag 补位）

★ 另外：拖动到箱子上时本机会主动"让路"，让游戏走它自己的放置逻辑 ——
  所以拖进箱子是"放进去"，不会误触发改值窗。


外观


沿用原版红色标签打印机的外观，形状压到 1×2 格（原版是 2×3），图也等比缩到贴合格子 ——
都是为了让供货商货架上放得下。


配置项（ModManager → 真实打印机）

项 | 默认 | 说明
FeatureCost | 20 | 改一次真值收多少信用点，设 0 = 免费
VerboseLog | 关 | 详细日志。默认只打启动横幅、自检结论与报错；勾上才看流水
SupplierStock | 开 | 供货商每次摆库存追加一台真实打印机
EnableF6Give | 关 | F6 直领开关。打开后按 F6 领取价值 0 的机器；关闭时不响应
DragToUse | 开 | 拖动触发。关掉后退回旧用法：只能先使用/装备再左键点
MarkStolenOnEdit | 开 | 改真值成功后给目标打赃物标记（之后由原版系统按热度处理）；关 = 只改真值

★ cfg 改了立刻生效，不用重启游戏。


常见问题


症状 | 怎么办
mod 完全没反应 | UserData/MelonPreferences.cfg 里没有 [RealPrinter] 段 → mod 没被加载，确认 DLL 放对了
拖到商品上没反应 | 面板确认 DragToUse 是开的；再确认松手位置压在商品上（不是空格子）。若仍无反应，看启动日志有没有「交互补丁 3/3 全部就绪 ✓」
拖进箱子没进去 | 箱子满了，或该箱子不接受本机。看启动日志有没有「官方档位目录就绪」与建机相关报错
左键点物品没反应 | 先确认机器是"使用 / 装备"状态（不是拖动中）。若仍无反应，看启动日志有没有「Harmony 补丁已挂 ✓」
F6 按了没反应 | 正常 —— EnableF6Give 默认关闭。想用去 ModManager 勾上
供货商来了但货里没打印机 | 柜台满了。日志搜 [供货商]；打「回读前柜台没找到」= 被游戏静默销毁，等下次补货
机器图比格子大 | 缩图失败，3 秒后自动重试；摆货与交互完全不受影响，只是显示溢出
改了没生效 | 面板勾上 VerboseLog，看「已执行档位动作」+「商品侧回读 最终 GetNegociatedValue=」
提示里"价值 X → X ★没变" | 说明真没改。勾 VerboseLog 看回读断言
读档后失效 | 勾 VerboseLog 看「读档检查完成」的指针白名单条数（应 ≥1）
拖动机器会闪退 | v1.5.0 已把开窗推迟到拖动结束后的下一帧，并加了指针漂移闸。若仍出现，
                  先把 DragToUse 关掉（退回 v1.4.x 用法），并把日志发我
面板里出现两行 RealPrinter | Mods/ 目录里有两个版本的 DLL，删掉旧的
